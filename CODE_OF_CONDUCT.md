# Code of Conduct

Be civil. Argue about data and thresholds, not people. Credit NASA/JPL and ESA. Don’t sell this as an official alert system.

No harassment, spam, or doxxing.

Report to the maintainer (`lib/site.ts` / About). We may close Issues/PRs that break this.

Loosely based on the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
